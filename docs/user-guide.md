## 1. 開始使用與漢堡導覽選單

**MoonCode 月海程式學習室** 可在電腦與手機瀏覽器開啟使用。所有學習紀錄預設優先安全寫入裝置本機的 IndexedDB，即使尚未設定 GitHub 雲端同步，也能完整閱讀教材、作答測驗並匯出備份。

> **關於本手冊截圖**：所有畫面均擷取自潔淨隔離的同版本實機網站；示例作答與錯題僅作為流程展示，不會讀取您的個人紀錄。初次在全新裝置開啟時，首頁測驗數與錯題數顯示 `0`、掌握度顯示「待測」均屬正常情況。

### 開啟與切換導覽步驟

1. 開啟 MoonCode 網址進入 **首頁總覽**，頂部右側會顯示目前狀態（「本機模式」或同步／最近儲存時間）與主要按鈕 **「儲存」**。
2. **電腦版操作**：點擊左上角三條橫線漢堡按鈕（切換章節與功能導覽選單），即可展開或收合左側導覽欄；上方「學習導覽」列有 `首頁總覽`、`題庫瀏覽`、`錯題本`、`掌握度`、`AI 工作台`、`儲存與版本`、`系統文件下載` 與 `設定`，下方則為 `C# OOP 與 MVC 教材（9 章）`。
3. **手機版操作**：點擊左上角漢堡按鈕打開全高導覽抽屜，選取任一功能或章節後抽屜會自動收合；亦可點擊右上角 `X` 關閉，介面支援 375px 窄螢幕不會橫向溢出。
4. 在首頁可直接點擊橫幅右側的 **「繼續教材學習」**（若有尚未完成的測驗，按鈕會自動顯示為 **「繼續未完成測驗（第 X/10 題）」**），或從下方「課程章節地圖（第 1 至第 9 章）」任一卡片點擊 **「讀簡報 →」** 進入教材。

## 2. 閱讀章節簡報與步驟模擬

1. 從左側導覽選單或首頁章節地圖進入任一章節（例如 **「1. 類別與物件」**）。
2. 頁面頂部可透過下拉選單快速切換第 1 至第 9 章，或點擊 **「做本章測驗」** 直接前往對應章節題庫；下方編號按鈕（例如 `1. 為什麼需要類別 (Class)？` 至 `6.`）可隨時切換該章各頁簡報，電腦版亦可用鍵盤左右方向鍵換頁。
3. **閱讀內容結構**：左側「原版核心鎖定區」呈現核心結論、關鍵專有名詞對照（附英文）、白話講解、生活比喻與**比喻邊界（不可過度類比）**，以及程式預期行為與學習目標；右側呈現固定深海護眼藍青配色的 C# 程式碼（右上角可點擊 **「複製」**）。
4. **步驟模擬／結果推演**：當簡報附有互動推演區時，可依序點擊 **「上一步」**、推演前進按鈕（例如第一步顯示設定的起始動作，後續顯示 **「下一步推演」**）與 **「重設」**，同步觀察對應的程式碼高亮行與狀態快照變化。

> **常見提醒**：模擬區下方明確標註「本互動為預定義步驟模擬／結果推演，供觀察物件與資料流動；瀏覽器端不執行真實 C# 編譯器」，請勿將此互動視為線上 C# 編譯環境。

## 3. 自訂比喻、版面切換與安全改寫保護

當內建比喻不夠貼近自身經驗，或想調整閱讀編排時，可在簡報頁面安全改寫呈現方式，**無需擔心改壞核心觀念或程式碼**：

1. 在簡報列點擊 **「自訂比喻與版面」** 展開微調表單。
2. 僅可調整 `生活比喻故事`、`精確概念對照`、`比喻適用邊界`、`白話補充說明`、`講解詳盡層級`（精簡版／標準版／詳盡版）與 `簡報呈現布局`（雙欄並排 `split_code`／單欄聚焦 `focused_concept`／對照整理 `comparison_columns`）。
3. 確認修改後點擊 **「儲存改寫版」**，系統會以獨立 `SlideVariant` 保存至本機，頂部立即出現 **「個人／AI 改寫版 (rev N)」** 與 **「原版教材」** 切換按鈕，可隨時對照查看。
4. 若想請 ChatGPT Plus 協助改寫，可點擊右側 **「請 ChatGPT Plus 改寫比喻」** 自動帶入章節與簡報頁前往 AI 工作台；若不再需要改寫版本，點擊 **「還原原版」** 即可恢復原版教材（原始核心定義、C# 程式碼、預期行為與評閱依據全程保持鎖定不可更動）。

## 4. 篩選題庫與開始 10 題測驗

1. 從漢堡導覽點擊 **「題庫瀏覽」**（或在簡報末尾點擊 **「完成本章簡報，前往第 N 章題組測驗」**）。
2. 利用上方 5 個篩選條件縮小範圍：`章節`、`核心概念`、`難度`（基礎／進階／綜合挑戰）、`來源`（內建教材種子題組／ChatGPT Plus 匯入題組）與 `作答狀態`（全部題組／尚未完成／已完成過）。
3. 確認每張題組卡片標示的章節、涵蓋概念數及固定題型組合（`7 題單選題 + 3 題理解題，共 10 題`）。
4. 點擊右下角 **「開始 10 題測驗」**；若該題組有先前作答到一半的紀錄，按鈕會顯示為 **「繼續進行中的測驗」**，點擊後可直接接續上次進度與計時狀態。

## 5. 逐題作答、計時暫停與查看測驗結果

### 逐題作答與計時控制

1. 進入測驗後，畫面一次只顯示一題（上方標示 `第 1 / 10 題` 與題型標籤）。右上角顯示即時 **「有效作答」** 計時器與 **「暫停」** 按鈕。
2. **單選題（第 1–7 題）**：必須選取其中一個選項後，方可送出；未選擇時送出會提示錯誤訊息。
3. **理解作答題（第 8–10 題）**：請在輸入框用自己的話說明設計原因、責任歸屬或取捨。只要內容非空白即可送出（不要求逐字背誦、也不以字數長短拒收）。
4. **暫停與離開中斷**：需要休息時點擊 **「暫停」**，計時隨即停止（按鈕轉為 **「繼續計時」**）；若作答途中切換瀏覽器分頁或視窗失去焦點，系統會自動暫停有效計時並標註「已標記離開／暫停，本題僅計正確率不計速度加成」。
5. **送出並前進**：第 1 至第 9 題點擊右下角 **「確認作答並下一題」**；最後第 10 題按鈕文字為 **「送出最後一題並查看結果」**。每題送出後答案與用時即鎖定並寫入本機 IndexedDB；答錯仍可繼續前進，可透過上方編號按鈕回頭唯讀檢視已送出題目（全部 10 題完成前不會顯示解析）。

### 查看結果與待 AI 判讀狀態

6. 第 10 題送出後自動進入結果頁。頂部顯示 **「單選題 X / 7」**，若 3 題理解題尚未批改則明確標示 **「總成績尚未完整」** 與 **「待 AI 判讀（未判讀不算答錯）」**。請勿將「待 AI 判讀」誤認為答錯。
7. 結果頁會解鎖全部 10 題之參考解答、解析與各題有效／總時長；若發現題目選項或行為有疑義，可點擊該題右上角 **「回報題目異常」** 記錄問題並選擇將該題從統計排除。

## 6. 使用 AI 工作台出題、評閱與改寫（TXT 提示詞與 JSON 檔案往返）

本系統預設啟用 **「Plus 手動 JSON 往返模式（已啟用）」**，無須支付額外 API 費用；畫面亦清楚區分 **送給 ChatGPT：提示詞 `.txt` 檔案** 與 **從 ChatGPT 帶回網站：回覆 `.json` 檔案**，並標示 **「官方自動連線擴充介面（未啟用）」**。

### 完整檔案往返 5 步驟

1. 從導覽列進入 **「AI 工作台」**（若仍有未批改理解題，選單會括號提示 `(N 待評)`），依需求選擇三項任務之一：
   - **任務 A：產生 7+3 新題組**：選擇目標章節，提示詞會自動帶入該章概念掌握情形與近期題目去重清單。
   - **任務 B：批次評閱 3 題理解題**：需先完成一組 10 題測驗且內含 3 題「待 AI 判讀」的理解題才可選取；若尚無待評測驗會顯示 `0 組待評`。
   - **任務 C：改寫簡報比喻與版面**：指定章節、簡報頁、改寫範圍與補充提示。
2. 點擊 **「產生提示詞與 Request ID」**。產生完成後，點擊主按鈕 **「下載提示詞（.txt）」** 取得純 UTF-8 純文字檔（檔名包含任務與 `requestId`，例如 `mooncode-evaluate-short-answers-...txt`；尚未產生提示詞前下載按鈕會停用）。接著點擊 **「另開 ChatGPT Plus 分頁」**，將此 `.txt` 檔案直接附加給 ChatGPT Plus 送出（畫面亦保留「提示詞純文字預覽」與 **「複製提示詞（備用）」**）。
   - 若您需要重下同一份提示詞，直接再點 **「下載提示詞（.txt）」** 或於「本機 AI 請求紀錄」點 **「下載 .txt」** 即可，**不會建立多餘的新請求**；唯有主動點擊 **「重新產生（建立新 Request ID）」** 才會產生新一筆請求。
3. 提示詞已要求 ChatGPT **優先建立並回傳可下載的純 UTF-8 `.json` 檔案附件**（僅在無法產檔時才直接輸出原始 JSON）。請下載 ChatGPT 回覆的 `.json` 檔案，回到 MoonCode 步驟 2 點擊 **「匯入 .json 檔案」**（若 ChatGPT 未提供檔案，才於「JSON 內容預覽／貼上備用區」貼回文字）。
4. 點擊 **「執行完整 Schema 與安全性驗證」**。若因網頁複製混入 `&quot;` 或行尾反斜線導致 JSON 格式損毀、或缺少欄位／試圖修改鎖定程式碼／`requestId`、`answerHash`、`Epoch` 不符，系統會拒絕套用並提示建議使用 `.json` 檔案；驗證通過後出現綠色摘要，再由您點擊 **「確認套用至本機資料庫」** 完成寫入。
5. **獨立追蹤多筆請求**：下方「本機 AI 請求紀錄（供核對 requestId）」會分別標示每筆 `Request ID` 的真實狀態（**「已套用」** 或 **「待回覆」**）。重複匯入同一筆已套用的評閱結果會自動跳過不重複計分，且不會把舊結果套用到另一筆仍為「待回覆」的請求。

## 7. 錯題本檢視、重練與區分清理動作

1. 從導覽點擊 **「錯題本」**。頁面僅收錄 **已評閱且判定答錯** 的紀錄；待 AI 判讀中的理解題絕不會出現在此頁。
2. 可依 `錯題狀態`（仍待複習錯題／曾錯但後續重練已答對／全部歷史錯題紀錄）、`章節`、`概念` 與 `時間範圍` 進行篩選。
3. 若為剛開始使用或篩選下沒有錯誤紀錄，畫面會誠實顯示 **「目前篩選條件下沒有錯題紀錄。」**；有錯題時每張卡片會並排呈現「當時回答」、「正確答案／參考理解」、「解析」與歷史作答次數，點擊右下角 **「重練原題組」** 可開啟新一輪測驗（重練答對後仍可在「曾錯但後續重練已答對」回看最初錯誤）。
4. **清理時請務必確認兩個按鈕的差異**：
   - **「移出複習清單 (保留統計)」**：只把該題從日常複習清單隱藏，**保留原本這筆作答記錄作為概念掌握度依據**。
   - **「重置此筆作答紀錄」**（需再點 **「確認重置」**）：建立移除標記，把該筆作答自掌握指標與複習排程中完全剔除並重算。

## 8. 理解掌握度指標與間隔複習

1. 從導覽點擊 **「掌握度」**，頁首即列出演算法 `v1.0.0` 的性質說明：本指標為可解釋的練習綜合指標，並非心理計量考試機率預測。
2. **各章節掌握摘要**：顯示 9 章各自的 `已測 X / Y 概念`、章節加權指標與正確率；可點擊任一章節卡片篩選下方「概念掌握明細（26 項）」。若該章仍有未測概念，會明確標示 `評估未完成`。
3. **辨識概念標籤意義**：
   - **待測**：該概念尚無有效已判讀獨立作答，不給予 0 分或假分數。
   - **`（暫估）`**：當該概念累積的不同獨立題數未達 5 題，或練習跨日天數不足 2 天時顯示「樣本或跨日資料未達門檻（暫估 · 建議再測）」。
   - **速度資料尚不足／需確認**：唯有在「同難度且同閱讀量級、無中斷、未看提示」的正確單選題累積至少 5 筆先前樣本後，系統才會加入速度修正因子 `F`；理解題打字耗時僅作個人趨勢檢視，**不會因為打字慢而扣分**。若單選作答遠快於基準，則會額外標示「作答過快需再次確認」。
4. **間隔複習排程**：頁面底部依 `1 / 3 / 7 / 14 天` 間隔排序顯示建議複習概念與原因，可點擊右側 **「前往練習」** 直接帶入篩選前往題庫。

## 9. 儲存、StudyBundle 備份、同步與回到上一版

### 日常儲存、確認對話框與結果判讀

1. 日常作答測驗每一題或改寫簡報時，資料會自動靜默寫入本機 IndexedDB（不會每題跳出確認視窗）。
2. 當您點擊右上角主要按鈕 **「儲存」** 時，畫面會開啟 **「確認儲存」** 對話框，依目前真實狀態說明本次儲存與同步範圍（「本機模式」、「已完成授權並可同步雲端」或「離線或連線暫不可用」），並列出題組／作答筆數與最近確認時間。
3. 若只想取消本次手動檢查，點擊 **「取消」** 或按 `Escape` 即可安全關閉，不會呼叫同步，也不會清除或還原任何既有資料；點擊 **「確認儲存」** 後按鈕會鎖定並顯示「儲存中…」，待真正寫入本機與（若已授權且連線）完成雲端檢查後，頂端下方會出現明確結果通知：
   - **「已儲存至本機」**：本機模式確認本機 IndexedDB 保存成功（不會偽稱已同步雲端）。
   - **「已儲存至本機並完成同步」**：本機保存與 GitHub 私有倉庫同步皆已完成。
   - **「已儲存至本機，目前尚未同步」**：代表本機已妥善保存，但因離線或遠端同步失敗尚未上雲；通知列會附上原因與 **「重試同步」** 按鈕。
   - **「儲存失敗」**：表示本機寫入確認未通過；既有資料保持不變，也不會更新最近儲存時間，可點擊 **「重試儲存」**。

4. 進入左側 **「儲存與版本」**，在「完整學習封包備份與還原 (StudyBundle JSON)」點擊 **「下載完整備份 (StudyBundle)」**，可取得含 `integritySha256` 校驗碼的單檔 JSON（不含任何憑證），供換裝置或額外保留。
5. 欲匯入備份檔時，先選擇匯入模式——預設建議 **「合併匯入（保留現有資料並去重）」**，或改選 **「覆蓋還原（自動保留覆蓋前保護快照）」**——再點 **「選擇備份 JSON 匯入」**，背景 Web Worker 會驗證結構與版本（遇到更新版本檔案會安全拒絕，不損毀本機現有資料）。頁底亦提供「可讀性封存匯出（依章節）」與隱藏式「展開本機資料庫診斷資訊」。

### 啟用 GitHub 同步前置條件與版本復原

- **前置條件（必須預先於後端完成設定）**：單純在本機或純靜態網站（如 GitHub Pages）無法執行 GitHub 私有倉庫同步。必須由部署者在 GitHub 建立 **Private Repository**（初始化 README）與專用 **GitHub App**（僅授權 `Contents: Read and write` 與 `Metadata: Read-only`），並於後端部署環境（例如 Cloudflare Workers Secrets）設定好相關環境變數及白名單 User ID 後，再至「設定」頁點擊 **「使用 GitHub 帳號登入授權」** 才能啟用上方 **「立即儲存並同步」**。
- **恢復上一版與隔離區**：若同步後發現新版資料有誤，可點擊 **「恢復上一版」**（雲端模式需已授權且遠端 `Previous` 槽位存在；本機模式可還原覆蓋前保護快照）。當雲端完成正向復原而使 `SyncEpoch` 遞增後，另一台離線裝置下次連線同步時，舊待同步作業會被送進本頁的 **「隔離區」**，由您逐筆點擊 **「重新匯入目前 Epoch」** 或 **「安全丟棄」**。
- **可達性過期檔案清理 (Reachability GC)**：僅在已授權連線狀態可用，務必先按 **「預覽可清理物件 (Dry-Run)」** 確認未被現有與上一版引用的檔案數量，再按確認刪除按鈕（注意：Git 歷史 commit 本身仍會依 Git 機制保留）。

## 11. 下載系統文件與處理異常狀態

1. 點擊左上角漢堡按鈕（電腦版展開側欄／手機版開啟抽屜），在「儲存與版本」下方點擊 **「系統文件下載」**。
2. 確認頁面上方狀態列顯示 **「文件與網站版本一致」**，並可查看目前的 `文件版本` 與 `更新日期`。
3. 點擊兩張文件卡片下方的按鈕：
   - **「下載系統規格書 PDF」**（取得系統規格、公式與資料規範 PDF）
   - **「下載使用操作手冊 PDF」**（取得本圖文操作手冊 PDF）
4. **桌面與手機瀏覽器行為差異**：
   - 桌面瀏覽器通常會直接將 PDF 下載至預設「下載」資料夾；下載完成後可用任何 PDF 閱讀器離線開啟。
   - 手機瀏覽器（特別是 iOS Safari）有時會直接在新分頁或預覽畫面開啟 PDF；此時請使用畫面工具列的「分享」→「儲存到檔案」保存至本機即可離線反覆閱讀。
5. **常見異常與處理方式**：
   - **顯示「文件版本核對警示」**：代表網站剛更新或瀏覽器快取到舊版文件索引。請先確認是否有頂部「立即更新」網站橫幅，或點擊 **「重新檢查文件」** 後再下載，切勿拿過期版本對照新系統操作。
   - **顯示「無法確認或下載系統文件」或下載中止警示**：若您處於第一次開啟或尚未快取過該 PDF 的離線狀態，頁面會如實提示需恢復網路連線後點擊 **「重試載入」**；若出現伺服器回傳非 PDF 檔案或檔頭檢核失敗，系統會立即攔截而不顯示下載成功，請通知維護者檢查建置產物。
